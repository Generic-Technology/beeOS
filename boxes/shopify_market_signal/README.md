# 市场信号盒（shopify_market_signal_box）

> 去外部平台看**公开的需求**：谁在公开地找什么、抱怨什么、想要什么。

## 它抓的是「需求主题」，不是「人」

一旦产出里有「谁想要」，它就变成了一台群发机器。
只出「外面有一类人在想 X」，它才是一只读盒。

**带个人信息的候选整条丢掉**（不是洗白）：带联系方式的帖子
不是需求信号，是有人在私下交易。

**它不写任何东西**——不发消息、不建受众、不改页面。

## 四个平台，全走官方 API——但**只有两个能给出站外需求**

（2026-11 逐个核实过官方文档；这张表的第三列是**核实后的结论**，不是愿望）

| 平台 | 拿什么 | 凭证 | **它能给出站外需求吗** |
| --- | --- | --- | --- |
| `gsc` | **我们自己店的**搜索词 + 曝光/点击/CTR/位置（第一方官方数据，不是爬虫） | `GSC_ACCESS_TOKEN` + `GSC_SITE_URL`，或投料给一条导出的 CSV | ✅ **能**——而且是四个里唯一给「买家搜什么」的 |
| `reddit` | 公开讨论里的「在找什么」 | `REDDIT_CLIENT_ID` + `REDDIT_CLIENT_SECRET` | ⏸ **暂时不能**：官方要求先审批（自助发证 2025-11-11 关闭，公开申请窗口 2026-10-31 关闭——第三方来源） |
| `etsy` | 自己店在售商品的标题/描述 | `ETSY_API_KEY`（+ `ETSY_API_SECRET`） | ❌ **不能**：`/v3/application/` 命名空间只返回**你自己店的**商品；要跨店，Etsy 只准 scraping（明令禁止） |
| `pinterest` | 自己账号的 Pin | `PINTEREST_ACCESS_TOKEN` | ❌ **不能**：官方 pin 搜索只覆盖**你自己的 Pin**，全站搜索是 beta、不给普通 app；还要商业账号 + 每个工作日审 |

**所以 Etsy / Pinterest 留着代码，但它们是「我们自己也在那上面开店时的运营工具」，
不是需求信号源**——别为了它们去注册账号（注册了也拿不到我们要的东西）。
代码留着是因为政策会变（就像 Reddit 那样），真变成可用了不用重写。

**GSC 的 CSV 那条路不用授权**：GSC → 搜索分析 → 导出 → 把文件路径投进来就能跑。

## 它在链上的位置

```
market_signal → snapshot → diagnosis → experiment → archive
```

**为什么在链首而不是挂在诊断上**：诊断要挂两个上游，环图就画不出来
（beeOS 的环要求相邻有交接边）。所以市场信号从链首进，
「这一轮的事实」= 店里的数据 + 外面在找什么。

## 验收只判三件机械的事

1. **产出里没有个人信息**（`pii_remaining_count == 0`）——安全底线
2. **每个平台都交代了取没取到**（取不到也要说清为什么）
3. **每条信号都有出处**（没出处的主题不算数）

**它不判「有多少条信号」**——需求信号本来就是长尾，
要求凑够条数，只会逼着盒子去凑数。

## 成熟度：skeleton

腿实现了，但**只有 GSC 的 CSV 那条路用夹具验过**；
其余平台要等凭证到位才跑得起来。第一次真跑过之后标 `live`。
