# 数学盒

拍一张作业照 → **错在哪 + 针对这些错怎么练**

| | |
|---|---|
| box_id | `learning_math_box` |
| 协作边界 | Learning |
| 价值流 | Learning |
| 成熟度 | **live**（腿是真的） |
| 判据 | 2 条（`ratio_exact` / `training_covers_errors`） |
| 例外 | 2 条（`ratio_exact == false` / `training_covers_errors == false` → escalate） |
| 接线 | `learning_growth_box`（本边界的汇点） |

## 它吃什么

**拍一张作业照就行**。照片之外的事实可以手填——**填了才用**，
照片读不出来的才需要补。

| 字段 | 是什么 |
|---|---|
| `photo` | 作业照片（手机拍的作业/试卷）。投了它，本盒会**看图**读出错题清单 |
| `activity` | 这次做了什么（作业 / 单元测 / 订正 / 复习） |
| `observed_at` | 学习发生的时间（ISO） |
| `evidence` | 出处：作业本 P12 / 单元测卷 / 口述 |
| `source_kind` | `observed`（真的看到了）/ `reported`（家里口述的） |
| `score` | 这次练习的得分 |
| `total` | 这次练习的满分 |
| `errors` | 这次错在哪（一条一个，人话摘要）——照片里没读出错题时填这里 |
| `notes` | 备注 |
| `minutes` | 花了多少分钟 |

## 它吐出什么

**一张错题训练卡**（这次的主产出），外加一条带出处的学习记录。

错题训练卡：

| 字段 | 是什么 |
|---|---|
| `wrong_questions` | 逐题：题号、题目、孩子的答案、正确答案、错因、错在哪 |
| `wrong_count` | 错了几题 |
| `verified_right_count` | 「看着像错题、算下来是对的」剔掉了几道 |
| `error_types` | 这次出现了哪几类错因（去重，**从错题清单里算出来的**） |
| `training_plan` | 按错因分组的针对性训练：练什么、怎么练、练哪几题、多少分钟 |
| `training_summary` | 一句人话：这次错在哪、下一步怎么练 |
| `training_covers_errors` | 方案有没有盖住每一类错因（**代码保证盖住**，这条判据守的是代码） |
| `missing_fields` | 这次没拿到哪些事实（照片里没有、也没手填的） |

学习记录（交给成长记录盒的那一份）：`record_id` / `subject` / `activity` /
`observed_at` / `mastery` / `evidence` / `source_kind` / `detail` / `notes`，
外加一个 `ratio_exact`（装配跳复算过得分率）。

**产出字段是成长记录盒要收的那份形状的超集** ——
那边是消费者，那边说了算；两份必须接得上，
守卫盯着：`tests/test_learning_boxes.py`。

## 照片怎么读

- **看图是独立的一跳**（`math_read_photo`）：模型只**抄**图上印着的东西，
  认不出的字段留空——**不猜**。猜一个满分，错的是以后每一份档案里的比率。
- **判错因是另一跳**（`math_analyze`）：抄图只会抄，判不了「这题是进位错
  还是概念错」。两件事分开，看图失败和判断失败才分得开。
- **手工填的优先，照片只补空**：人填的是他当场知道的；
  两边都有时以人填的为准，不悄悄叠成一个说不清是谁说的数。
- **错题有三态**：读到了错题 / 看得全而且每题都对 / **看不清**。
  「看不清」跟「都对」是两件事——把它俩混成一个空数组，
  等于跟家长说这次全对。
- **缺什么一次报齐**：少了日期、少了满分，履约会中止并把要补的字段一次列全
  （「照片里没读出来学习发生的时间（observed_at）」）。
- **投了照片就不能标 `reported`**：照片是「看到了」的证据。
- **图片字节不进产出**：产出只带照片的指纹（`evidence` 里写着
  `作业照片 photo:<指纹>`），不带着几 MB 的 base64 落盘。

## 错题是**算出来**的，不是看出来的

看图那一跳只**抄候选题**（它分不清红叉、对勾和批改痕迹）。
到底哪几题真的错了，**靠算**：算出正确答案，跟孩子的答案比，
一样的就**剔出错题清单**（剔掉几道写在 `verified_right_count` 里）。

- 实测过：一张作业照上「4 道错题」里**有 2 道其实是对的**。
  不剔的话，家长今晚要照着练的是**做对的题**。
- 剔掉的那几道要在总结里说明白——不说明，家长会以为漏了题。

## 训练方案怎么来的

- **错因是固定的表**（计算失误 / 概念不清 / 审题不清 / 步骤不全 /
  单位换算错 / 抄写笔误 / 未作答 / 其它）。自由文本没法按类分组，
  「计算错了」「算错了」「粗心」会变成三种。
- **一类错因一组方案**：练什么（`focus`）、怎么练（`how`）、
  练哪几题（`drills`）、多少分钟（`minutes`）。
- **方案一定盖住每一类错因**（`training_covers_errors`）。模型给的方案
  标签对不上号（判了「其它」、方案写在「计算失误」名下）时，
  **把标签改过来**——方法是对的，标签错了不该扔掉方法。
  模型压根没给，就机械兜底：**把这几道题逐题重做并讲一遍**
  （兜底的那组 `focus` 里写着「这次没看出具体练法」，不假装模型给过）。
  ——**不因为方案缺失就把整次履约判红**：家长拿到一张空卡加一句
  「未通过」，那是没用，不是诚实。
- **模型不许自己加题**：题号、题目、孩子的答案以抄下来的为准，
  模型能加的只有「判错因、补答案、出方案」。

## 读不出来的时候是 `n/a`，不是猜一个数

照片上常常没有得分、没有满分、没有日期。

- `mastery` 的口径**只有一个**：这次练习的**得分率**。
  读不出来时它是 `n/a`（这次这个量用不上），**不是 0，也不是猜一个 100**。
- `ratio_exact` 同理：没什么可复算的，就是 `n/a`。
- 缺了哪几个事实写在 `missing_fields` 里，**不藏**。
- 掌握度是 `n/a` 的记录**照样进成长档案**（`n/a` 是合法的掌握度），
  但**没有日期**的记录进不了档案——时间线上一条没有时间的记录没法排。
- **掌握度有没有越界不在本盒判**（那是档案腿的事，在成长记录盒判）。
  本盒的判据只管这张卡：**掌握度确实是得分率**、**方案盖住了每一类错因**。

## 它不干什么

- **不判断孩子学得好不好**。掌握度只是这次练习的**得分率**，
  不是评价，也不是预测。
- **不替家长下结论**。照片里看不清有没有错题，就说「没看出」，
  不说「都对」。
- **不替他说话**。`source_kind=reported` 的记录，
  半年后翻档案时仍然看得出它是「听说的」而不是「看到的」。

## 规矩（跟本仓其它盒子一样）

- **判据只判能机械判的**：读产出里的字段，不读「我觉得对不对」。
- **schema 归消费者所有**：本盒声明自己吃什么、吐什么。
- **不许 import 别的盒子**：`tests/test_layering.py` 管着这条。
- **业务知识住在盒子里**，不进 `core/`。
