# 经营档案盒（shopify_archive_box）

> 把一轮经营的快照、诊断、实验沉淀成**一条**带出处的记录。

**它是这个协作边界的唯一汇点**（出度 0，入度 3）。

## 它存结果，不存过程

三只上游盒子各自做自己那一段，过程产物留在它们自己那里；
本盒只沉淀「这一轮经营发生了什么」。

## 它自己复核，不信上游说「我过了」

上游会说自己「过了」（`metric_status_complete = true`）。
**它自己说的不算数**——这里重新算一遍：

- 快照段：每条指标状态合法吗？observed 有出处吗？unverifiable 有原因吗？
- 诊断段：证据引用非空吗？未知项列了吗？
- 实验段：变更项、停止条件、归因方式齐全吗？

复核结论进产出（`metric_status_honest`），因为产出是验收读数的地方。

**盒子说「我过了」就过了，没人回头核对它说的对不对**——
那是仓里已经踩过的坑（`boxes/wms_design/plugins.py` 就是为这件事存在的）。

## 三次投递归一条记录

档案盒跑三次（快照、诊断、实验各一次）。
**一个通道只能接一份产出**，所以三次是分开跑的；
归到同一条记录靠 `round_id`（`subject_ref_field`）。

**不定这一条，三条通道就是三条互不相干的归档记录。**

## 成熟度：live

这只盒子**不碰网络**：它只接住上游产出、复核、归档。
所以它现在就能真跑、真测。

**但它「活」不代表整条链活了**：上游三只还没在真店上跑过
（`read_reports` + Level 2 受保护客户数据审批还没下来）。
